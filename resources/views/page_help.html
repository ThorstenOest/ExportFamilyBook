Help: templates of the family book and the chart

The complete reference with all formats and many examples: Templates of ExportFamilyBook (GitHub, English). The README of the module describes profiles, branches, the image selection and how to make a PDF.

The file of the book: preamble, legend, list of sources, title, then per branch the headings, the summary and the entries, then the epilog.

Basic rules

  • The first four characters of a template define its special characters: opening and closing bracket of a block, placeholder character and format separator. Book: <>@&, chart: {}@&. These characters cannot be used as normal text.
  • A placeholder is a name between two @, formats follow after &: @BirthDate&%Y@. Names are case sensitive.
  • A block (text in brackets) is left out completely if no placeholder in it has data: < in @BirthPlace@>. Blocks can be nested. Double brackets <<...>> are written if they have data, but do not count as data for the block around them.
  • Line breaks of the template become spaces. Write \\ (LaTeX) or <br> (HTML) for a line break.
  • A loop repeats its text: @ForeachFAMS@ ... @EndForeach@. A pass without data is left out. Do not make the body of a loop one single block: write a space before it.
  • A date without format uses the default date format; without a default (always in the chart) it is empty.
  • Data are masked for LaTeX (&, %, _, ...) resp. HTML; the text of the templates is not.

Example

<>@&
\textbf{@SurName@, @GivenName@}
< *@BirthDate@< in @BirthPlace@>>
< \dejavu{†}@DeathDate@>\\

gives for example \textbf{Muster, Anna Maria Luise} *3.3.1850 in Musterstadt \dejavu{†}20.11.1920\\, and \textbf{Klein, Maria} \\ for an individual without dates.

Common errors

  • The export shows the form again with a message: a placeholder that does not exist, a bracket that is not closed, a loop without @EndForeach@.
  • A > or } in the text ends the block (e.g. -> in the book).
  • Empty dates in the chart: write a format, e.g. @BirthDate&%Y@.
  • A loop writes nothing: its body is one single block, or it has no data.
